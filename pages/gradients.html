CSS Gradients

Gradients allow you to display smooth transitions between two or more specified colors, replacing flat background colors with dynamic, modern depth.

Types include linear-gradient() (straight lines/angles) and radial-gradient() (circular/from a center point).

Gradient Syntax Example

How this dark monochrome background is made:


background: linear-gradient(135deg, #222222 0%, #141414 50%, #0d0d0d 100%);

  • 135deg: Controls the angle of the transition.
  • Color Stops: Smoothly blends from shade to shade across the viewport.
